# 鉴权拦截册（日切放行 / slicegate）

> 本册是写入口鉴权的唯一口径来源。服务启动时会校验本册与代码实现一致；不一致则拒绝启动并记录“鉴权口径偏了”。

## 当日锁定口径

- 口径代码：甲
- 锁定日期：2026-11-17（当日锁定，不许切换）
- 口径原文：非管理员角色写接口一律返回无权限且零写入
- 裁决结果：非管理员（含“只读”）调用任意写接口 → HTTP 403，业务表零写入
- 审计写入：拒绝与争用只写 `auth_events` 审计表，不写 `slices` / `releases` / `watermarks` / `slice_ops`

## 明确禁止

- 禁止乙口径混用：不允许只读角色写审计申请单、再由管理员审批执行的写法。
- 禁止只靠前端隐藏按钮：前端禁用仅作提示，服务端必须独立鉴权。
- 禁止只读令牌写成功放行、重切、放行回拨或水位。
- 禁止只改无权限提示而不动服务端拦截。

## 写入口清单（全部服务端鉴权）

| 方法 | 路径 | 动作 |
|------|------|------|
| POST | `/api/slices` | 切片登记 |
| POST | `/api/slices/{sid}/evaluate` | 完整度重裁 |
| POST | `/api/slices/{sid}/release` | 下游放行 |
| POST | `/api/slices/{sid}/recut` | 重切 |
| POST | `/api/releases/{rid}/rollback` | 放行回拨（按放行流水） |
| POST | `/api/slices/{sid}/rollback` | 放行回拨（按切片/消费方） |

## 并发裁决

- 同一写入口按资源串行：`slices:new`、`slice:{id}`、`releases:rollback`。
- 不同角色先后进入同一写入口时，后手必须落 `auth_events`，事件类型为“鉴权争用”，不得静默通过。
- 角色裁决在取得串行写锁之后执行：管理员执行，非管理员返回 403。
- 非管理员尝试写入口时落 `auth_events`，事件类型为“鉴权口径偏了”，结果“拒绝”。

## 可核面

- 权限列表：`GET /api/auth/permissions`（含角色矩阵与放行流水按角色对账）
- 策略条：`GET /api/auth/policy`
- 水位页：`GET /api/watermarks`
- 详情旁注：`GET /api/slices/{sid}`
- 鉴权事件：`GET /api/auth/events`
- 本册摘要：`GET /api/auth/ledger`（返回路径与 SHA-256）
