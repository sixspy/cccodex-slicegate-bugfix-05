# 日切放行

> 遵守 `ops/底座生成前必读_效率与技术栈.md`。FastAPI + Vue 3 + SQLite，交付须 docker compose 一键起；库用 SQLite，不挂外置 Postgres。  
> **禁止同构换皮**：本仓主链路、表结构、接口与页面均独立，不得与其它仓共用同一套 `/api/items` 壳。

## 骨架一句话

业务日分区切片登记后裁决完整度，完整才放行下游，并与消费水位对账

## 写入口鉴权（服务端强制）

- 六个写入口全部过 `write_guard`：切片登记、完整度重裁、下游放行、重切、放行回拨（按流水 / 按切片）。
- 只读令牌调用任一写入口 → `403 无权限：写入口仅管理员，已零写入`，业务表零写入，只落 `auth_events` 审计。
- 同一写入口按资源串行（`slices:new`、`slice:{id}`、`releases:rollback`）；后手进入时落“鉴权争用”事件，按角色裁决，不静默通过。
- 鉴权拦截册被改动/篡改时，启动拒绝，写入口返回 `503 鉴权口径偏了`，并落“鉴权口径偏了”事件。
- 前端按钮禁用只作提示，不承担鉴权。

## 可核面

| 页面/接口 | 用途 |
|-----------|------|
| 顶部策略条 | 口径代码、锁定日期、规则原文、鉴权拦截册 SHA-256 |
| `GET /api/auth/permissions` | 权限列表、写入口清单、放行流水按角色对账、被拒/争用计数 |
| `GET /api/auth/policy` | 策略条数据与鉴权拦截册校验结果 |
| `GET /api/auth/events` | 鉴权事件（拒绝、争用、基线） |
| `GET /api/slices/{id}` | 切片详情旁注（可写性说明、操作留痕） |
| 消费水位页 | 水位随放行写入、随回拨回退 |

## 放行 / 重切 / 回拨

- 完整度非“完整”禁止放行（409）；已放行切片须先回拨才能重放或重切。
- 回拨：成功流水改“已回拨”，写“回拨”流水，删对应水位，并按剩余成功流水回退切片放行态。
- 重切：更新实收/期望与完整度，未放行切片才可重切，全部留 `slice_ops` 与 `auth_events`。

## 为何能出多题

迟到切片、重切、跨分区依赖、部分完整冻结、消费水位回拨

## 避开

别做成作业拓扑编排换皮；别做成纯水位大盘

## 互斥切口候选

- 迟到切片整批拒收 vs 进待补齐冻结区
- 重切失败整笔回滚 vs 保留已完整分区
- 放行与水位同步闸 vs 异步放行后纠偏
